# AGENTS.md

Репозиторий создан из шаблона `hexlet-components/component-template`. Шаблон ставит общий слой проверок из [dev-quality-gates](https://github.com/mokevnin/dev-quality-gates): mise, hk, commitlint, rumdl, typos, lychee, jactionlint и betterleaks. Проверки под стек репозитория шаблон не знает, их добавляет первая настройка.

## Стенд

`compose.yml` описывает стенд курса `kafka_cli_course` из hexlet-exercise-kit. Вывод команд в уроках снят на нём, поэтому адреса, номера брокеров, `CLUSTER_ID` и ускоренные проверки очистки меняются вместе с уроками. Версию образа поднимает Dependabot, после подъёма вывод в уроках перепроверяется на новом стенде.

Все сервисы живут в сетевом пространстве сервиса `net`, отсюда одинаковые адреса `localhost:909x` на компьютере и в контейнерах. Брокер слушает все интерфейсы (`PLAINTEXT://:9092`), потому что проброшенный порт приходит на внешний интерфейс контейнера.

`mise run test` запускает `bin/smoke-test`.
